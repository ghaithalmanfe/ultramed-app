# Initial Listing 2026 — قائمة الأصناف الأولية

مقترح قائمة أصناف من 3 مراحل لعروض الأسعار (الصيدليات أولاً ثم العيادات)،
مبني على حركة البيع الفعلية من ERP للفترة 03/01/2026 → 06/09/2026.

## الملفات

| الملف | الوصف |
|---|---|
| `UltraMed-Initial-Listing-2026.xlsx` | المستند النهائي بالعربية (8 أوراق: المقترح · المراحل الثلاث · عرض الصيدليات · عرض العيادات · خارج القائمة · المعايير) |
| `UltraMed-Initial-Listing-2026-EN.xlsx` | English version of the same document (identical figures and rules) |
| `classify.py` | توزيع الأصناف على المراحل والقنوات حسب القواعد المكتوبة في ورقة «المعايير» |
| `clinic_evidence.py` | تحليل فواتير فريق العيادات (رانوفا أيمن + مريم زهير) على مستوى الحساب والطلب: الانتشار، إعادة الطلب، فاتحات الحسابات، السلال |
| `merge_evidence.py` | دمج أدلة العيادات في التصنيف: الترقية بالدليل، تنبيهات الاعتماد، تصحيح القناة |
| `price_join.py` | ربط قائمة الأسعار بالقائمة: كود فريد ← مطابقة عائلة مُراجَعة ← حجز المكرر والمتعارض |
| `pricing.py` | السعر الفعلي والهامش لكل قناة (صافي ÷ كل القطع المُسلَّمة، لأن الخصم يُمنح بضاعةً مجانية) |
| `price_gaps.py` | فجوات التسعير: بلا سعر · تعارض ERP · هامش رقيق · كود مكرر · صفوف بلا حركة |
| `build.py` | بناء ملف الإكسل العربي من مخرجات `classify.py` |
| `build_en.py` | بناء النسخة الإنجليزية من نفس المخرجات |

## إعادة التوليد

```bash
pip install openpyxl
python3 classify.py        # يقرأ list.json المستخرج من ملف حركة المنتجات، ويكتب classified.json
python3 clinic_evidence.py # يقرأ raw.json (فواتير ERP الخام) ويكتب clinic_evidence.json
python3 merge_evidence.py  # يدمج الأدلة في classified.json
python3 price_join.py      # يقرأ pricelist.json ويُسنِد سعر الجمهور
python3 pricing.py         # يحسب السعر الفعلي والهامش لكل قناة
python3 price_gaps.py      # يكتب price_gaps.json
python3 build.py      # يكتب UltraMed-Initial-Listing-2026.xlsx
python3 build_en.py   # يكتب UltraMed-Initial-Listing-2026-EN.xlsx
```

`list.json` يُستخرج من ورقة «القائمة List» في ملف حركة المنتجات
(`UltraMedProductMovement2026.xlsx`)، و`raw.json` من ورقة `MonthlySalesSummary` في ملف
الفواتير الخام (`Ultramed_Sales3_19.xlsx`). كلاهما غير محفوظ هنا لأنهما بيانات مبيعات خام.

## أدلة العيادات

الملف مُسنَد بتحليل فواتير رانوفا أيمن ومريم زهير: 41 حساب عيادة/مستشفى/طبيب · 283 طلب ·
114 صنفاً. أضاف ثلاث أوراق (أدلة العيادات · حسابات العيادات · سلال الطلبات) وغيّر القائمة في
ثلاثة مواضع: ترقية 4 أصناف إلى المرحلة 1 بدليل الانتشار وإعادة الطلب، تعليم 6 أصناف تعتمد على
عيادة أو عيادتين، ونقل براند UNIVET إلى قناة «مباشر / أونلاين» بعد أن تبيّن أنه لم يبع لأي
عيادة في 2026.

## التسعير

قائمة الأسعار (117 صنفاً، `products.csv`) مربوطة بالقائمة عبر الكود ثم بمطابقة عائلات
مُراجَعة يدوياً. أضافت ورقتين (التسعير والهوامش · فجوات التسعير) وأربع نتائج:

- 44 من 57 صنفاً في المرحلة 1 لها سعر معتمد؛ الـ 13 الباقية كلها مهنية — عرض الصيدليات
  جاهز، وعرض العيادات لا يمكن إصداره من قائمة الأسعار الحالية.
- الخصم يُمنح بضاعةً مجانية لا بخفض السعر: نُفوتر بسعر القائمة كاملاً مع 25–47% مجاني،
  فالسعر الفعلي = صافي المبيعات ÷ كل القطع المُسلَّمة.
- هامش الصيدلية 20–48%، وكل أصناف Philips عند 20% بالضبط بلا مجاني.
- 10 تعارضات سعرية بين ERP وقائمة الأسعار، و9 أكواد مكررة، و37 صفاً بلا حركة مقابلة.
