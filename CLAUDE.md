# UltraMed Field Ops — working notes for Claude

Kuwait dental-products field-sales PWA (two reps + a supervisor). Everything the
team sees must be true: never report "saved" when it did not land, never show a
figure that cannot be explained on screen.

## Layout
- `www/index.html` — the app (markup, CSS, and the inline app script). `APP_REV` at the top must match `CACHE` in `www/sw.js`; bump both on every release.
- `www/js/core.js` — pure, unit-tested helpers (dates, ERP parsing, merges, month achievement, the daily e-mail digest). Browser-free; `require`-able from Node.
- `www/js/i18n.js` — the English → Arabic dictionary (exact-string matches).
- `www/netlify/functions/` — the Netlify functions the site actually deploys (`assistant`, `daily-report`, scheduled `daily-morning` / `daily-evening`); shared code in `www/netlify/lib/`. There is deliberately no root `netlify/` folder and no `netlify.toml`: the site publishes `www` and picks functions up from `www/netlify/functions`.
- Storage: Firestore collection `state`, one document per key `{value: JSON string, updated}`; merge-safe lists (`visits`, `tasks`, `clinics`, `events`, `dayPlans`) go through an atomic read-merge-write; ERP rows live in chunk documents `erpRows:<period>:<rev>:<n>`.

## Tests (run before every push)
- `npm test` — unit tests in `tests/*.test.js` (core helpers, daily report).
- `npm run e2e` — browser harnesses in `tests/e2e/*.e2e.js` (Playwright + Chromium, a fake cloud, a fixed clock). Run one with `node tests/e2e/smoke-all.e2e.js`. `WWW=<path>` points them at another checkout; `CHROME_PATH` picks a browser (the Claude cloud container's is found automatically).
- GitHub Actions runs both on every push (`.github/workflows/tests.yml`).
- Harness numbers use a synthetic ERP file generated by `tests/e2e/fixtures/make-sales-xlsx.js` — do not commit real sales files.

## Releasing
1. Work on `claude/hello-0r7ps7`; bump `APP_REV` and the service-worker `CACHE`.
2. Commit, push the branch, merge into `main` with a `Deploy vNN: …` merge commit, push `main`. Netlify publishes `main` automatically (https://resonant-granita-6e6cce.netlify.app); confirm with `curl …/sw.js`.
3. Tell the user to open the app twice per device so the new service worker takes over.

## House rules
- Arabic replies to the user, plain language, no code in prose.
- Reproduce a bug with a harness check before fixing it; keep the check.
- Month figures: one code path (`UMCore.monthAchievement`) serves the Today card, the reports and the e-mail — never compute them elsewhere.
